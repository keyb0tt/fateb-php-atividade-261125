# 📘 Exercícios de HTML e PHP --- Lista Completa

Este repositório contém a implementação manuscrita (reescrita em código)
de uma lista completa de exercícios propostos para prática de **HTML**,
**PHP**, **lógica de programação**, **estruturas condicionais**,
**vetores**, **laços de repetição** e **operações com Banco de Dados**.

Cada exercício foi separado em sua própria pasta, contendo:

-   `index.html` → Formulário de entrada\
-   `processa.php` → Lógica PHP do exercício
